## 왜 옮겼나 / Why

naia 데스크톱 앱은 제품 언어로 이제 **비주얼 에이전트(visual agent)** 라고 부릅니다.

- **`naia-shell`** — 셸·앱·워크스페이스를 담는 **코드 저장소** (개발은 여기서)
- **`naia-os`** — Bazzite 기반 **배포판/ISO** 이름으로 계속 사용
- 내부 구조(agent = 커널)는 여전히 *AI OS* 은유를 유지합니다

The desktop app is now called a **visual agent**. The shell/app/workspace **code** lives in
**`naia-shell`**; the name `naia-os` now refers to the Bazzite-based **distro/ISO**.
